# TAYF (Flutter)

TAYF bulmaca oyununun Flutter/Android sürümü. Depo kökündeki `index.html` web
sürümüdür; mobil için bu proje kullanılır.

Kurulum, imzalama, Android uyarlamaları ve F-Droid yayını için depo kökündeki
[`README.md`](../README.md) dosyasına bakın.

```bash
flutter pub get
flutter run
flutter build apk --release
```
